# axchisan/scoop-bucket

[Scoop](https://scoop.sh) bucket by [axchisan](https://github.com/axchisan).

```powershell
scoop bucket add axchisan https://github.com/axchisan/scoop-bucket
scoop install axchisan/lost-and-prompt
```

| App | Description |
|---|---|
| [lost-and-prompt](https://github.com/axchisan/lost-and-prompt) | Find, organize and resume all your Claude Code sessions |

New versions are picked up automatically from the GitHub releases.
